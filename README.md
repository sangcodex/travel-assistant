# 旅游助手

用 Pi 做行程的多智能体项目。个人项目，2026.05 – 2026.07。

## 项目是什么

天气、交通、景点和酒店要分开查，再合成一条能走完的路线。

## 我做了什么

- 做了中心调度：负责拆任务，再把四个结果合成行程。
- 天气、交通、景点、酒店四个专职智能体各自使用独立会话，并且只挂自己的工具。
- 专职智能体只回传时间窗、费用和不确定点。搜索过程留在自己的会话里，不把噪音交回调度。
- 行程同时约束开放时间、换乘、排队、预算和舒适度。某个时间窗排不开，或中途改了需求，就只重跑受影响的智能体和路段。
- 每次新查询开启新会话。旧会话留下来做复盘。

这个仓库目前只放项目说明。
