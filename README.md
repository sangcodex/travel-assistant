# 旅游助手

基于 Pi 的多智能体行程助手。个人项目，2026.05 – 2026.07。

## 做了什么

一次行程要同时处理天气、交通、景点和酒店。中心调度智能体负责拆开任务，再把结果合成一条行程。下面四个专职智能体各自跑在独立会话里，并且只挂自己的工具。

专职智能体不把搜索过程交回调度，只回传压缩后的时间窗、费用和不确定点，把探索过程的噪音留在自己的会话里。

合成全局行程时，同时约束开放时间、换乘耗时、排队、预算和舒适度。某个时间窗排不开，就只把对应的专职智能体退回去重查。

每次新查询都开启一个新会话，旧会话留下来做复盘。遇到交通延误、天气变化，或者用户中途改需求，只重跑受影响的智能体和路段，已经确认的结果继续用。

这个仓库目前只放项目说明。
